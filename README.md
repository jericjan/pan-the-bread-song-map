# Pan the Bread Song Map
A map of every song Pan the Bread has every sung either through official dedicated uploads or through karaoke streams.

This was made on Capacities, but visualization features were limited there so it also contains configs for Obsidian. I recommend viewing the graph using the Digent View plugin. It's really pretty while also being able to visualize how everything is connected.

There is a `clean_images.py` script. This is mostly for me when exporting from Capacities. Capacities includes a `previewImage` property in the YAML frontmatter. It's completely useless and points to a Untitled file that doesn't exist. This script removes that property.
